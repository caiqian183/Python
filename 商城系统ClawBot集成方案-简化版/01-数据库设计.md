# 数据库设计（简化版）

## 数据库表结构

### 1. 用户表 (users)
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 2. ClawBot绑定表 (clawbot_bindings)
```sql
CREATE TABLE clawbot_bindings (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    wechat_bot_token VARCHAR(255),
    wechat_user_id VARCHAR(255),
    wechat_nickname VARCHAR(100),
    binding_status ENUM('pending', 'bound', 'unbound', 'error') DEFAULT 'pending',
    qr_code_data TEXT,
    qr_code_expires_at DATETIME,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_id (user_id),
    INDEX idx_status (binding_status)
);
```

### 3. 微信消息表 (wechat_messages)
```sql
CREATE TABLE wechat_messages (
    id INT PRIMARY KEY AUTO_INCREMENT,
    binding_id INT NOT NULL,
    message_id VARCHAR(255),
    content TEXT,
    sender_id VARCHAR(255),
    sent_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (binding_id) REFERENCES clawbot_bindings(id) ON DELETE CASCADE,
    INDEX idx_binding_id (binding_id),
    INDEX idx_sent_at (sent_at)
);
```

### 4. ClawBot网关配置表 (clawbot_gateway_config)
```sql
CREATE TABLE clawbot_gateway_config (
    id INT PRIMARY KEY AUTO_INCREMENT,
    config_key VARCHAR(100) UNIQUE NOT NULL,
    config_value TEXT,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
