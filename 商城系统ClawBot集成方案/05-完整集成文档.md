## 概述

本方案帮助您在商城系统中集成微信 ClawBot，实现以下功能：

- ✅ 用户在个人后台绑定微信 ClawBot
- ✅ 订单状态变更实时通知到微信
- ✅ 用户通过微信查询订单和商品信息
- ✅ 智能客服对话
- ✅ 多用户独立会话管理
- ✅ 消息历史记录

### 核心特性

| 特性 | 说明 |
|------|------|
| 官方合规 | 使用微信官方 ClawBot 插件，无封号风险 |
| 多用户支持 | 每个用户独立绑定，数据隔离 |
| 实时通知 | 订单状态变更即时推送 |
| 智能查询 | 用户可通过微信查询订单信息 |
| 易于集成 | 提供完整的 API 和 SDK |

## 系统架构

```
┌─────────────┐
│   微信用户   │
└──────┬──────┘
       │
       │ 微信消息
       │
┌──────▼──────────────────┐
│   微信 ClawBot 插件     │
└──────┬──────────────────┘
       │
       │ iLink 协议
       │
┌──────▼──────────────────┐
│  ClawBot Gateway       │
│  (多用户路由网关)       │
└──────┬──────────────────┘
       │
       │ HTTP Webhook
       │
┌──────▼──────────────────┐
│   商城系统后端           │
│  (FastAPI/Node.js等)    │
└──────┬──────────────────┘
       │
       ├────────────┬────────────┐
       │            │            │
┌──────▼──┐  ┌───▼──────┐ ┌──▼───────┐
│ 数据库   │  │  订单服务  │ │  用户服务  │
└─────────┘  └──────────┘ └──────────┘
       │
       │
┌──────▼──────────────────┐
│   商城系统前端           │
│  (用户个人中心)          │
└─────────────────────────┘
```

### 数据流向

1. **绑定流程**：用户 → 商城前端 → 商城后端 → ClawBot Gateway → 微信
2. **通知流程**：订单服务 → 商城后端 → ClawBot Gateway → 微信用户
3. **查询流程**：微信用户 → ClawBot Gateway → 商城后端 → 数据库 → 返回结果

|---------|------|------|
| `/api/clawbot/bind/init/{user_id}` | POST | 初始化绑定，生成二维码 |

## API 文档

### 1. 初始化绑定

**请求：**
```http
POST /api/clawbot/bind/init/{user_id}
```

**响应：**
```json
{
  "qr_code_base64": "data:image/png;base64,...",
  "expires_at": "2026-04-16T12:00:00Z"
}
```

### 2. 检查绑定状态

**请求：**
```http
GET /api/clawbot/bind/status/{user_id}
```

**响应：**
```json
{
  "binding_id": 1,
  "status": "bound",
  "wechat_nickname": "微信用户"
}
```

### 3. 解绑

**请求：**
```http
POST /api/clawbot/unbind/{user_id}
```

**响应：**
```json
{
  "success": true,
  "message": "解绑成功"
}
```

### 4. 发送消息

**请求：**
```http
POST /api/clawbot/message/send
Content-Type: application/json

{
  "user_id": 1,
  "message": "您的订单已发货！",
  "message_type": "text"
}
```

**响应：**
```json
{
  "success": true,
  "message_id": "msg_1234567890"
}
```

### 5. Webhook 接收

**请求（来自 ClawBot Gateway）：**
```http
POST /api/clawbot/webhook
Content-Type: application/json
X-API-Key: your-webhook-api-key

{
  "type": "message",
  "data": {
    "from_user_id": "wx_user_123",
    "content": "查询我的订单",
    "message_id": "msg_abc123"
  }
}
```

**响应：**
```json
{
  "reply": "您的最近订单：\n• 订单 #12345 - 配送中 - ¥299.00"
}
```

## 故障排查

### 常见问题

#### 1. 用户无法绑定

**可能原因：**
- ClawBot Gateway 未运行
- 微信版本过低
- 网络连接问题

**解决方案：**
```bash
# 检查网关状态
clawbot-gateway status

# 查看网关日志
clawbot-gateway logs -n 100

# 检查微信版本（需要 8.0.70+）
```

#### 2. 消息无法发送

**可能原因：**
- Webhook URL 配置错误
- API 密钥不匹配
- 防火墙拦截

**解决方案：**
```python
# 测试 Webhook 连接
import httpx

async def test_webhook():
    try:
        response = await httpx.post(
            "https://your-domain.com/api/clawbot/webhook",
            headers={"X-API-Key": "your-webhook-api-key"},
            json={"type": "test", "data": {}}
        )
        print(f"Status: {response.status_code}")
        print(f"Response: {response.text}")
    except Exception as e:
        print(f"Error: {e}")
```

#### 3. 绑定状态检查失败

**可能原因：**
- 数据库连接问题
- 用户 ID 不存在
- 会话过期

**解决方案：**
```sql
-- 检查绑定记录
SELECT * FROM clawbot_bindings WHERE user_id = 1;

-- 检查数据库连接
SELECT 1;
```

#### 4. 订单通知未收到

**可能原因：**
- 用户未绑定
- 通知创建失败
- 消息发送队列堆积

**解决方案：**
```sql
-- 检查通知记录
SELECT * FROM order_notifications 
WHERE user_id = 1 
ORDER BY created_at DESC 
LIMIT 10;

-- 检查用户绑定状态
SELECT * FROM clawbot_bindings 
WHERE user_id = 1 AND binding_status = 'bound';
```

### 监控告警

```python
# 添加健康检查端点
@app.get("/health")
async def health_check(db: Session = Depends(get_db)):
    """健康检查"""
    try:
        # 检查数据库
        db.execute("SELECT 1")
        
        # 检查网关连接
```
